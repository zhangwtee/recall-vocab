# recall-vocab

主动回忆式背单词工具，单文件 HTML，零依赖。目标四级，同时内置多本词书。

核心交互：屏幕先只出英文单词。你想出中文意思就直接输入并自动判分；想不出来则点「不认识 / 模糊 / 认识」三档自评。两条路在同一张卡上并存。

调度用 FSRS-5，按记忆稳定性动态安排复习间隔；进度、助记、打卡记录只存在本地浏览器，导出 JSON 即可备份迁移。

## 直接使用的三种方式

1. **本地**：下载 `index.html`，双击用浏览器打开。首次需联网取词库，之后缓存到本地，断网也能背。
2. **手机**：把整个仓库部署到任意静态托管（GitHub Pages / Gitee Pages / Cloudflare Pages 均可），手机浏览器打开后，从菜单选「添加到主屏幕」，全屏使用，跟 App 一样。
3. **只带一个 HTML 文件**：`index.html` 本身不含词库。首次打开会自动从下面的源取词库并缓存，取到后就不必再联网。

## 词库源

启动时按顺序自动切换，取到即用，并写入本地缓存：

1. jsDelivr CDN（GitHub 仓库镜像）
2. Gitee 仓库 raw
3. GitHub 仓库 raw

索引与例句分离：`data/books.js`（词书与词池）、`data/examples.js`（例句）。

也可在「设置 → 数据 → 词库源」里填自定义目录 URL，格式为包含 `books.js` 和 `examples.js` 的目录，例如：

```
https://gitee.com/你的账号/你的仓库/raw/main/data
```

填错或不可达时会自动回退到官方源。

## 重新构建

```bash
node build-app.js
```

把 `fsrs.js`、`words.js`、`loader.js` 注入 `app-template.html` 生成 `index.html`，并把 `books.js`、`examples.js` 复制到 `data/`。词库数据由 `build-books.js` 和 `build-examples.js` 从原始词表生成。

## 目录说明

- `index.html` — 成品，可直接双击
- `data/` — 词库文件，部署时必须与 index.html 同目录
- `app-template.html` — 界面与逻辑源码
- `loader.js` — 词库加载器（多源切换、IndexedDB 缓存、离线回退）
- `fsrs.js` — FSRS-5 调度实现
- `words.js` / `books.js` / `examples.js` — 词表、词书分类、例句数据
- `liuxiaoyan.js` / `build-liuxiaoyan.js` — 刘晓艳四级核心词的解析结果和生成脚本
- `extract-official.py` — 从官方 2016 大纲 PDF 提取带 ★ 词表，拆分四六级
- `raw/official-cet4.txt` / `raw/official-cet6.txt` — 官方词形表（供构建复用，随仓库提交）
- `audit-data.js` — 词库数据结构体检（可重复运行，不改动数据）
- `audit-meaning.js` — 释义溯源审计：核对主释义是否来自可信来源、哨兵词是否正确、有无占位或噪声
- `test-*.mjs` — 端到端测试（Edge 无头浏览器 + CDP），其中 `test-meaning-e2e.mjs` 验证词库释义与卡片显示、判分一致，`test-official.mjs` 验证官方词书可选、可出题

## 官方四六级大纲词（2016 修订版）

教育部教育考试院《全国大学英语四、六级考试大纲（2016年修订版）》附的词表是唯一官方词汇依据。词表只列词形，不注音标、不给释义；带 ★ 的词目为六级新增，不带 ★ 的为四级。官方统计：词目 5418 个、派生词 2551 个（六级全部 7969 词），其中四级 4147 词目、2161 派生词（6308 词）。

据此拆成两本词书，放在词书选择器顶部：

- **大学 → 四级 → 官方四级大纲(2016)**：5800 余个四级词形，实际入书 5698 词
- **大学 → 六级 → 官方六级新增(2016)**：1600 余个带 ★ 词形，实际入书 1599 词

释义复用词池里已有的高可信来源，不采用官方表自带的释义（它没有）。实际入书词数略少于提取词形数，是因为词池里查不到可靠释义的派生词被剔除，不塞占位假释义。

提取方式：`extract-official.py` 从官方 PDF 第 21–149 页按版面坐标提取词条，保留 ★ 分级，清洗页眉页码与同形异义序号，输出 `raw/official-cet4.txt` 和 `raw/official-cet6.txt`。PDF 可从 `cet.neea.edu.cn` 下载（文件名 `cet2016.pdf`，放到系统临时目录或 `raw/`）。`audit-data.js` 会校验两本书的词形全部来自官方 PDF、无交叉、无空释义。

## 刘晓艳四级核心词

「大学 → 四级 → 刘晓艳四级核心词」收录《英语四级·你还在背单词吗》的 2327 个核心词条，按原书课次顺序排列。词条自带书中助记（2005 条）和真题例句（2327 条），揭晓后直接显示在卡片上；也可以在单词档案里查看。

这部分数据来自公开开源项目 `Owenwoow/cet4-vocab-courseware` 整理的 JSON，例句为该项目 AI 生成的书外补充。原始素材已下载到 `raw/liuxiaoyan/`，由 `build-liuxiaoyan.js` 转换后并入词池。

## 释义来源

主释义来自各原始词表（已修正 OCR 错位的音标符号、逗号多拼写与括号变形等解析遗漏，并按英美拼写差异补全占位词）。

多来源合并时按可信度取用，不按释义长度：四级/六级/中高考等考试词书优先，英专/GRE/TOEFL 次之，COCA 词典爬虫数据最后。这样可避免词书里正确的简洁释义被其他来源里更长但带 OCR 错字、排版错位或不相关义项的文本覆盖。COCA 释义中的人名、地名、音译片段与领域标记在入库前已剔除；查不到释义的词不再塞「大纲词」占位，而是从词书中剔除。

部分词条另附「牛津高阶参考」——来自 OALD8 精简数据，原文繁体已转简体，只在揭晓页和单词档案中作参考，不覆盖主释义。该数据只覆盖词池中的一部分词。

## 词序

词书内的词按 COCA 词频升序排列，先学常用词；`the`、`be`、`and` 这类超基础功能词排到末尾，不必专门背；没有词频数据的词最后按字母序兜底。每天的新词照此顺序引入，不再随机打乱。刘晓艳四级核心词按原书课次排列，保持配套课程的顺序。

多义词的义项顺序整体沿用原词书（常用义本就在前）。少数原书按词性或义项先后排列、导致常用义在后的同形异义词做了人工核校：`well`（好/井）、`march`（行军/三月）、`miss`（想念/小姐）、`pick`（采摘/镐）、`pitch`（投掷/沥青）、`swallow`（吞下/燕子）、`sound`（声音/健康的）、`spring`（春天/跳跃）、`rock`（岩石/摇动）、`used`（过去常常/旧的）。只调整义项块顺序，文字原样保留；`audit-data.js` 会校验这些词的首位义项。

## 说明

词库数据来自公开词表整理，例句来自 `KyleBing/english-vocabulary`。学习进度不会上传，全部保存在当前设备的浏览器里。
