# recall-vocab

主动回忆式背单词工具，单文件 HTML，零依赖。目标四级，同时内置多本词书。

核心交互：屏幕先只出英文单词。你想出中文意思就直接输入并自动判分；想不出来则点「不认识 / 模糊 / 认识」三档自评。两条路在同一张卡上并存。

调度用 FSRS-5，按记忆稳定性动态安排复习间隔；进度、助记、打卡记录只存在本地浏览器，导出 JSON 即可备份迁移。

## 学习辅助

- **写中文 / 拼英文**：卡片上可切换输入模式。拼英文时题面换成中文义项，英文和音标都收起来，揭晓后才显示；错一个字母算「接近」，补上只认得、写不出的短板。它同样参与判分和排期。
- **撤销误判**：点「下一词」后可在新卡上撤销上一次评分，卡片状态、当日统计和队列一起还原，手滑不会污染复习计划。
- **手动复习**：「今日计划 → 复习昨天学的 / 复习近 3 天」把那些天学过的词插到队首，再评一次按新反馈重新排期。
- **负载控制**：复习堆积时用「今天少背 10 个」压低当天新词上限，次日自动恢复；点单词卡可标记「熟知」，该词移出队列不再出现。
- **出现时自动朗读**：新词一出现就读一遍，默认开启，在设置里可关。揭晓后朗读是另一个独立开关。个别手机浏览器禁止无手势的自动播放，第一次碰屏幕时会补读当前词。
- **回看上一词**：新卡和反馈页都有「回看上一词」，只看意思和例句，不改评分、统计和队列，看完点「回到当前词」。
- **错义分析**：写错的中文会留下来；统计页的「错义分析」按输入分组，反查词库里同义的词，并按词形相似度排序，用来发现「把 advance 想成 evidence」这类混淆。记录只存本地，可一键清空。
- **揭晓后再拼**：反馈页的「再拼一次这个词」把英文藏起来，看中文重新拼一遍，只做提示，不计入 FSRS 排期和当日统计。

## 直接使用的三种方式

1. **本地**：下载 `index.html`，双击用浏览器打开。首次需联网取词库，之后缓存到本地，断网也能背。
2. **手机**：把整个仓库部署到任意静态托管（GitHub Pages / Cloudflare Pages / EdgeOne Pages 均可），手机浏览器打开后，从菜单选「添加到主屏幕」，全屏使用，跟 App 一样。
3. **单文件版（最省事）**：`node build-single.js` 生成 `memo.html`，词池与例句全部内联，一个文件约 5.4 MB，**完全不联网**。发到手机上用浏览器打开即可，不需要部署，也不需要配置。

## 词库源

启动时按顺序自动切换，取到即用，并写入本地缓存：

1. jsDelivr CDN（GitHub 仓库镜像）
2. Gitee 仓库 raw
3. GitHub 仓库 raw

索引与例句分离：`data/books.js`（词书与词池）、`data/examples.js`（例句）。

也可在「设置 → 数据 → 词库源」里填自定义目录 URL，格式为包含 `books.js` 和 `examples.js` 的目录，例如：

```
https://gitee.com/你的账号/你的仓库/raw/main/data
```

填错或不可达时会自动回退到官方源。

## 重新构建

```bash
node build-app.js      # 生成 index.html + data/
node build-single.js   # 生成完全离线的单文件版 memo.html
```

`build-app.js` 把 `fsrs.js`、`words.js`、`loader.js` 注入 `app-template.html` 生成 `index.html`，并把 `books.js`、`examples.js` 复制到 `data/`。词库数据由 `build-books.js` 和 `build-examples.js` 从原始词表生成。

`build-single.js` 在此之上再内联 `books.js`、`examples.js`，并把加载器替换为直接返回内置词库的桩，因此产物不发起任何网络请求。`test-single.mjs` 用拦截全部域名解析的方式验证它在断网下可用。

## 目录说明

- `index.html` — 成品，可直接双击
- `memo.html` — 单文件离线版（构建产物，不随仓库提交）
- `data/` — 词库文件，部署时必须与 index.html 同目录
- `app-template.html` — 界面与逻辑源码
- `build-app.js` / `build-single.js` — 分别生成 `index.html` 与 `memo.html`
- `loader.js` — 词库加载器（多源切换、IndexedDB 缓存、离线回退）
- `fsrs.js` — FSRS-5 调度实现
- `words.js` / `books.js` / `examples.js` — 词表、词书分类、例句数据
- `liuxiaoyan.js` / `build-liuxiaoyan.js` — 刘晓艳四级核心词的解析结果和生成脚本
- `extract-official.py` — 从官方 2016 大纲 PDF 提取带 ★ 词表，拆分四六级
- `raw/official-cet4.txt` / `raw/official-cet6.txt` — 官方词形表（供构建复用，随仓库提交）
- `raw/sense-extra.json` — 人工补充的常见义项，词典漏收时使用（随仓库提交）
- `audit-data.js` — 词库数据结构体检（可重复运行，不改动数据）
- `audit-meaning.js` — 释义溯源审计：核对主释义是否来自可信来源、哨兵词是否正确、有无占位或噪声
- `test-*.mjs` — 端到端测试（Edge 无头浏览器 + CDP），其中 `test-meaning-e2e.mjs` 验证词库释义与卡片显示、判分一致，`test-official.mjs` 验证官方词书可选、可出题，`test-single.mjs` 在断网（拦截全部域名解析）下验证单文件版可用且进度能存，`test-tts.mjs` 验证系统语音不出声时退回在线音频、失败提示只弹一次，`test-layout.mjs` 在 360/390/414 三种手机宽度下验证标签不折行、判定条与对比框不粘连、两个操作按钮之间留有间隙且同高、操作栏不压住底部统计，`test-improve.mjs` 验证撤销误判、手动复习、临时减量与熟知标记、拼写模式，`test-autospeak.mjs` 验证出词自动朗读、设置开关、失败静默与首次手势补读，`test-revisit.mjs` 验证回看上一词、错义记录与分析、揭晓后拼写复盘，`test-ui.mjs` 验证例句标签位置、日历点格子看日期、遗忘曲线用真实数据定位

## 官方四六级大纲词（2016 修订版）

教育部教育考试院《全国大学英语四、六级考试大纲（2016年修订版）》附的词表是唯一官方词汇依据。词表只列词形，不注音标、不给释义；带 ★ 的词目为六级新增，不带 ★ 的为四级。官方统计：词目 5418 个、派生词 2551 个（六级全部 7969 词），其中四级 4147 词目、2161 派生词（6308 词）。

据此拆成两本词书，放在词书选择器顶部：

- **大学 → 四级 → 官方四级大纲(2016)**：5800 余个四级词形，实际入书 5698 词
- **大学 → 六级 → 官方六级新增(2016)**：1600 余个带 ★ 词形，实际入书 1599 词

释义复用词池里已有的高可信来源，不采用官方表自带的释义（它没有）。实际入书词数略少于提取词形数，是因为词池里查不到可靠释义的派生词被剔除，不塞占位假释义。

提取方式：`extract-official.py` 从官方 PDF 第 21–149 页按版面坐标提取词条，保留 ★ 分级，清洗页眉页码与同形异义序号，输出 `raw/official-cet4.txt` 和 `raw/official-cet6.txt`。PDF 可从 `cet.neea.edu.cn` 下载（文件名 `cet2016.pdf`，放到系统临时目录或 `raw/`）。`audit-data.js` 会校验两本书的词形全部来自官方 PDF、无交叉、无空释义。

## 刘晓艳四级核心词

「大学 → 四级 → 刘晓艳四级核心词」收录《英语四级·你还在背单词吗》的 2327 个核心词条，按原书课次顺序排列。词条自带书中助记（2005 条）和真题例句（2327 条），揭晓后直接显示在卡片上；也可以在单词档案里查看。

这部分数据来自公开开源项目 `Owenwoow/cet4-vocab-courseware` 整理的 JSON，例句为该项目 AI 生成的书外补充。原始素材已下载到 `raw/liuxiaoyan/`，由 `build-liuxiaoyan.js` 转换后并入词池。

## 释义来源

主释义来自各原始词表（已修正 OCR 错位的音标符号、逗号多拼写与括号变形等解析遗漏，并按英美拼写差异补全占位词）。

多来源合并时按可信度取用，不按释义长度：四级/六级/中高考等考试词书优先，英专/GRE/TOEFL 次之，COCA 词典爬虫数据最后。这样可避免词书里正确的简洁释义被其他来源里更长但带 OCR 错字、排版错位或不相关义项的文本覆盖。COCA 释义中的人名、地名、音译片段与领域标记在入库前已剔除；查不到释义的词不再塞「大纲词」占位，而是从词书中剔除。

部分词条另附「牛津高阶参考」——来自 OALD8 精简数据，原文繁体已转简体，只在揭晓页和单词档案中作参考，不覆盖主释义。该数据只覆盖词池中的一部分词。

考试词书的释义偏简，常只列一两个义项。为了不让用户答对却被判错，`build-books.js` 会从 COCA 词典义项里挑出主释义没有、但确实常见的义项，存进 `alt` 字段。`alt` 只参与判分，并在揭晓页以「另有」列出，不改动已审计的主释义。

词典本身也会漏（`view` 只给「观察；视野；意见；风景」，没有最常用的「观点」），这类由 `raw/sense-extra.json` 人工补充。人工条目对该词整条覆盖词典结果，避免又把不相关的义项掺回来；同样要过「不与主释义汉字重合」的校验。

## 统计与界面

统计页的遗忘曲线按 FSRS 公式画理论曲线，再把已学词按「距上次复习时间 ÷ 记忆稳定性」的实际位置叠上去：绿色圆点代表你的词，点越大代表落在同一区间的词越多，点会随复习情况移动；没背词时只有蓝色理论曲线。打卡日历的格子可以直接点，格子下方显示对应日期、星期和当天的新词/复习/评分数量，手机上不用悬停也能看。

例句标签放在第一个例句框的左上角，与英文同一行，不单独占一整行，给手机竖屏省出高度。

## 判分与朗读

输入的中文按词性和中英文标点切成独立义项再比对，所以「a.迟的 ad.迟，晚」拆成「迟的 / 迟 / 晚」，答「迟到」「晚」都算对；一次写多个义项时，任意一段命中即可。「的地得了着」这类虚词差异、以及「其它/其他」这类异体写法在比较前归一。

判分阈值以上算对，中间区间算接近（按「模糊」计），其余不算。反义字只差一个字的（内部/外部、前一/后一）不会因为字形接近而被判为部分正确。

朗读优先用系统语音引擎；引擎缺失、或没装英文语音导致调用后不出声，会退到在线词典音频。单词和较短的英文例句都会尝试这条降级链，但在线词库并不收录所有句子，个别句子仍可能读不出来；Chrome / Safari 自带英文语音时最稳。两者都不可用时提示一次，不会每次点击都弹同一个报错。出词时的自动朗读走同一条链，失败时静默；手动点喇叭仍会提示。同一张卡重复渲染不会重复朗读，拼英文模式在揭晓前也不朗读，免得报答案。

## 词序

词书内的词按 COCA 词频升序排列，先学常用词；`the`、`be`、`and` 这类超基础功能词排到末尾，不必专门背；没有词频数据的词最后按字母序兜底。每天的新词照此顺序引入，不再随机打乱。刘晓艳四级核心词按原书课次排列，保持配套课程的顺序。

多义词的义项顺序整体沿用原词书（常用义本就在前）。少数原书按词性或义项先后排列、导致常用义在后的同形异义词做了人工核校：`well`（好/井）、`march`（行军/三月）、`miss`（想念/小姐）、`pick`（采摘/镐）、`pitch`（投掷/沥青）、`swallow`（吞下/燕子）、`sound`（声音/健康的）、`spring`（春天/跳跃）、`rock`（岩石/摇动）、`used`（过去常常/旧的）。只调整义项块顺序，文字原样保留；`audit-data.js` 会校验这些词的首位义项。
